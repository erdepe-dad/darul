# Code of Conduct

## Our standard

Darul contributors and maintainers are expected to create a respectful, constructive, and technically rigorous community.

Acceptable behavior includes:

- Giving specific, actionable feedback
- Disagreeing with ideas without attacking people
- Respecting privacy, attribution, and project security
- Welcoming contributors with different experience levels and backgrounds
- Correcting mistakes openly and professionally

Unacceptable behavior includes harassment, discrimination, threats, sexualized conduct, deliberate humiliation, disclosure of private information, credential sharing, or sustained disruption of project spaces.

## Scope

This policy applies in issues, pull requests, discussions, reviews, community channels, and public interactions where someone represents the project.

## Enforcement

Report conduct concerns privately to the maintainers through an appropriate private GitHub channel. Do not use public security reports for ordinary conduct disputes.

Maintainers may edit or remove content, issue warnings, temporarily restrict participation, or permanently ban participants. Enforcement decisions should consider context, impact, repetition, and community safety.

Good-faith reports must not be used as a basis for retaliation.
