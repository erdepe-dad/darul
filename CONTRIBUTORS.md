# Contributors

Darul is maintained as an open-source project. Thank you to everyone who reports issues, improves documentation, tests releases, reviews changes, and contributes code.

## Project maintainers

- [erdepe-dad](https://github.com/erdepe-dad) — creator and maintainer

## Adding contributors

Contributors may add themselves in the pull request that contains their first accepted contribution. Use a GitHub profile link and a short factual description of the contribution area. Do not add email addresses or other personal details without explicit consent.
